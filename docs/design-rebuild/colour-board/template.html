Why the app looks dull, and how themes fix it

You were right, and it is measurable. On a normal day under 3% of the Today screen carries any colour, and switching from Orange to Indigo changes about 1% of it. The theme exists, but it almost never reaches the screen.

2.7%of Today's pixels have any colour. The rest is white, paper and grey text.
0.1%of Settings has colour. Task and Progress are near 1.2%.
1.0%of Today changes when you switch Orange to Indigo.
0%of Settings changes when you switch theme, the screen where you choose it.

What makes it dull

  1. Colour is rationed to small marks. On Today only the task icons, the add button and the active tab are coloured. The biggest thing on the screen, the 79% card, is black on white.
  2. The theme barely shows. It reaches the add button, the active tab and a few links. Picking Indigo or Berry does not feel like it did anything.
  3. The two colours that carry the idea are whispered. Ideal green and fallback blue appear as thin outlines in sage and dusty blue.
  4. Success has no colour. A task you logged looks like one you did not, plus a small chip. A finished day looks like an empty one.
  5. All four themes share one mood. Page, cards and borders are the same warm grey whichever theme is chosen.

How a theme should work

A theme is one seed colour. The app derives every other shade from it by rule, and checks each pair for contrast, so a theme cannot produce unreadable text. This is the theme you are viewing now:

Three colours never change with the theme, because they mean something. Themes are kept away from these hues so they cannot be confused.
